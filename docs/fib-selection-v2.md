# Fib 候选区间规则 v2

规则标识保存在 `impulseCondition.selectionVersion`：`pullback-v2` 为新规则，缺省或 `legacy-v1` 为旧规则。

## 选择与生命周期

- 仅扫描已完成右侧确认的 Pivot。高点按时间倒序，低点也按时间倒序；原涨幅、跨度、回看及放量门槛不变。
- 包含端点的低高点区间不得有更高的 High。高点之后曾有收盘严格破高或破低的组合不能复活。
- 未持仓候选锁定。小波动、影线突破后收回、等于高低点均不失效；收盘严格破高、破低或低点回看过期时清除候选和入场边沿，可在同根使用另一个已确认且有效的组合入场。
- 首次成交独立复制锚点。加仓、失效及 Fib 止盈止损使用首次入场锚点，持仓后突破不重新选点。
- 平仓后重建下一轮候选；保留原来“卖出同根不再次首次买入”的限制。实时执行在确认卖出成交后准备下一轮，未决实盘卖单不清空持仓。

## 兼容与发布

- 创建策略版本、从策略创建回测/实时任务，服务端写入新规则。旧版本不修改。
- 已提交回测、重试和原任务“重新回测”沿用配置快照。历史批量研究 manifest 和排名不改变。
- `portfolio-6` / 检查点 v5 保存规则、候选和边沿。旧 v2–v4 检查点只允许在原有兼容条件及 legacy 规则下恢复；规则不匹配明确拒绝，不自动从头运行。
- 运行中实时任务切换为 `closed-bar-v3`，在原 JSON 写入新规则，记录切换时间和 `execution_switched` 事件中的原持仓快照；不修改历史订单。取消旧模拟待成交意图，未决实盘订单继续核验，不开启实盘权限。
- 未持仓项目从已有闭合历史逐根重建候选，预热不发订单；既有连接恢复及完整收盘边界保护继续生效。已持仓保持数量、成本、锚点和锁盈状态。
- 新版本说明生成器 v2 描述新规则，任务详情单独显示实际执行规则，避免与旧版本说明混淆。
- 新版本配置校验值使用排序后的 JSON 键，避免 JSONB 返回顺序改变哈希；不修改已存校验值或任务引擎校验和。
