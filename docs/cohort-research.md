# 信号日期分组研究

这是历史 CA 分组稳健性检验，不是未见市场时期的时间外检验。早期信号项目的完整行情可能和后期项目重叠，既有数据也可能被此前研究看过。

## 执行与恢复

1. 完成三链导入并检查 JSONL 最后一个 `summary`。导入的部分成功、无行情和缺失主池均进入快照审计；无终态不能导出。
2. `DATABASE_URL` 仅供只读一致性快照导出，以及明确 `--submit` 的新任务服务器复验使用，禁止打印连接字符串。`cohort-snapshot.mjs OUTPUT IMPORT_REPORT` 导出三链四种行情及信号、版本和既有报告元数据；重复读事务保证同一个快照。
3. `node --max-old-space-size=6144 scripts/cohort-research.mjs SNAPSHOT OUTPUT sol` 在本地运行（同样支持 robin、bsc）。每链 512 个候选，固定种子、同一成本、同一数据；检查点缓存允许相同协议恢复，不允许换参数后继续使用旧验证结果。
4. `cohort-pipeline.mjs --output DIR --import-report FILE --import-pid PID [--submit --api URL]` 等待正在运行的导入，顺序在本机执行三链研究，避免 16 GiB Mac 同时加载多链行情。导入进程失败或等待超过 24 小时会停止，不在残缺批次上悄悄研究。
5. `cohort-server-verify.mjs SNAPSHOT STUDY OUTPUT API --submit` 只提交达标且成本压力通过的前三个候选。建立新的已停止任务，上传并回读同一冻结输入，然后经现有 retry 接口入队。不会修改旧任务，不读取变化中的源行情重新冻结。失败任务不自动重试，不覆盖已有结果；确定性任务 ID 防止重复创建。

## 固定标准

- 最早信号按北京时间自然日期切五段，日期跨度均分，不能按收益改变边界。同 CA 多池归同组。
- D1～D3 开发；先在两种周期合并排名后冻结最多十个候选，再打开 D4/D5。
- 开发期每段净收益正、至少 20 笔、回撤至多 10%；失败候选保留探索榜，不降低门槛。
- 同一链所有候选统一初始资金及成本；种子配置成本不同，逐项取手续费／滑点／税的较高值，记录在协议中，不降低成本来优化收益。
- 稳定性要求 D2～D5 每段满足以上条件，收益相对中位数偏差至多 50%，D4+D5 实际共享资金组合正收益且回撤至多 10%。日期组不足则不认证。
- 通过者评估单边滑点 +1 个百分点和全部 31 个非空组合，组合不是收益相加，也不是独立验证。真实重跑移除最大盈利 CA 的组合，揭示盈利集中度。
- 包含末根平仓，首次买入及加仓都严格在信号后。保留生产引擎的缺口处理、账户竞争与成本规则。

## 产物和审计

`state.json` 给出当前阶段；`snapshot/manifest.json` 包含校验值及导入问题清单；每链有 protocol、coverage、training、shortlist、evaluations、report。Markdown 汇总只展示已完成研究；不得把运行中探索榜当成稳定结论。

服务器任务使用新模板版本及输入快照，逐笔交易／事件规范化校验值须一致，收益与回撤容差 1e-7。不一致时停止并保留证据，不声称复验通过。验证矩阵的普通收益与成本压力收益必须分开解释。预先固定筛选标准仍不能消除数据选择偏差或未来流动性风险。

## 第二轮：小集合发现与相似集合、大集合验证

`node --max-old-space-size=6144 scripts/small-set-research.mjs SNAPSHOT PREVIOUS_STUDY NEW_OUTPUT`

仅使用同一本地冻结数据，不写生产、不自动上传策略。固定种子 20260923，按首次信号北京时间日期比例分配 CA，生成五个互斥小集合，每组最多 50 个，不足时取可用 CA 数除以五向下取整。少于 50 个可用 CA 时停止，不冒充充分验证。可用集合要求两个周期都有信号后有效行情，缺失者列出；这是数据覆盖筛选，不表示真实项目总体没有缺失偏差。所有池跟随同 CA；信号前历史用于指标，买入严格在信号后，包含末根平仓。

新一轮每链最多 512 个候选，成本沿用前轮；种子包括前轮发现榜，是明确的历史再探索，不称盲测。只在 S1 调参，净收益正、至少 10 笔、回撤不超过 10% 的前五候选冻结后再评估 S2～S5、除 S1 外的大集合、全量集合。大集合均重新合并时间线执行共享资金，而不是加总收益。

报告分别标明跨集合盈利与严格达标。严格达标要求四个验证小组及两个大集合都满足上述净收益/样本/回撤条件，四小组收益相对中位数偏差不超过 50%，单边滑点 +1pp 后也通过；独立大集合去掉最盈利 CA 后重新运行仍满足收益/样本/回撤要求。所有入选候选均展示压力和集中度结果，不只展示成功者。全量含发现组，仅作总体诊断，不视为独立验证。前轮报告、门槛和任务不变。
